# 🧠 IT Sual-Cavab Oyunu (Question Game with Simple JS)

Sadəcə xalis JavaScript ilə yazılmış, brauzerin daxili `confirm`, `prompt` və `alert` funksiyalarından istifadə edən IT mövzulu viktorina oyunu. İstifadəçiyə İT və texnologiya tarixi ilə bağlı 10 sual verilir, 4 səhv cavabdan sonra isə oyun dayanır.

## 🚀 Xüsusiyyətlər

- ❓ IT və texnologiya tarixinə dair 10 sual
- ✅ Hər düzgün cavab üçün xal artır
- ❌ 4 səhv cavabdan sonra oyun avtomatik dayanır
- 💬 Bütün qarşılıqlı əlaqə brauzerin `confirm`, `prompt` və `alert` pəncərələri ilə aparılır
- 📊 Nəticələr (düzgün/səhv sayı) brauzer konsolunda göstərilir

## 🛠️ İstifadə olunan texnologiyalar

- **HTML** — səhifənin skeleti
- **JavaScript** — bütün oyun məntiqi (heç bir kitabxana və ya framework yoxdur)

## 📁 Layihənin strukturu

```
question-game-with-simple-js/
├── index.html       # Əsas HTML fayl
└── questionGame.js  # Oyunun bütün məntiqi (suallar, cavablar, xal sistemi)
```

## ▶️ Necə işə salmaq olar

1. Repozitoriyanı klonlayın:
   ```bash
   git clone https://github.com/Narminkerimovaa/question-game-with-simple-js.git
   ```
2. Layihə qovluğuna keçin:
   ```bash
   cd question-game-with-simple-js
   ```
3. `index.html` faylını brauzerdə açın.

## 🎯 Necə oynanılır

1. Səhifə açılan kimi oyuna başlamaq üçün təsdiq pəncərəsi çıxır.
2. Təsdiqlədikdən sonra suallar bir-bir `prompt` pəncərəsində göstərilir.
3. Cavabınızı yazıb təsdiqləyin — böyük/kiçik hərf və boşluqlar əhəmiyyət daşımır.
4. Hər düzgün cavab xalınızı artırır, hər səhv cavab isə sizi 4 səhv hüququndan birini itirdiyiniz barədə xəbərdar edir.
5. 4 səhvdən sonra oyun dayanır, ya da bütün suallar bitdikdə oyun sona çatır.
